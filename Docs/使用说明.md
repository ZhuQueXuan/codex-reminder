# Codex 提醒助手 · 分享版

切到其他软件后，在 Codex 回答结束、提问或申请权限时，尝试将 Codex 窗口显示到前台。程序住在 Windows 右下角托盘，可暂停弹出或关闭声音。它不会替你批准、拒绝或回答问题。

## 第一次使用

1. 电脑需要 Windows 10/11、.NET Framework 4.8 或更高版本，以及已安装并登录的 Codex 桌面应用。本版本在 Windows 11 上检查过，其他电脑仍需实际验证。
2. **收到单文件安装 EXE**：打开 Codex，双击安装程序，点击“安装并启动”。它会自动解包到固定位置，并可创建桌面快捷方式，无需管理员身份。安装位置可在安装界面修改。
3. **收到 ZIP**：将 ZIP 完整解压到一个长期保留、可写入的普通文件夹，例如“文档\Codex提醒助手”。打开 Codex，再双击根目录的“首次安装并启动.cmd”。不要在压缩包里直接运行，也不要只取出其中的 EXE。两种安装方式都会保留原有其他事件，安装三个提醒事件并启动托盘程序。
4. **信任提醒配置**：如果 Codex 显示事件审阅入口，只信任带有 `CodexAttention` 的三个事件。如果桌面没有入口，双击根目录的 **打开事件审阅终端.cmd**，进入后输入 `/hooks`，查看并信任这三个事件，然后退出终端。如果未找到随 Codex 安装的终端，可在已经安装的 Codex CLI 中执行 `/hooks`，并使用与桌面相同的用户配置目录。
5. 回到 Codex，重新开始一个聊天回合。切到别的软件，等回复结束，确认能否自动弹回。托盘中的“测试弹出”只检查窗口切换，不能替代这一步。

未完成信任步骤时，自动完成与事件提醒不会生效。程序不会替用户完成信任。若仍提示未信任，重启 Codex 后再检查。

## 以后怎么用

EXE 安装后双击桌面的 **Codex提醒助手** 快捷方式即可；ZIP 版双击 **启动提醒助手.cmd**。没有创建桌面快捷方式时，在安装目录双击“启动提醒助手.cmd”。右下角找不到绿色 C 图标时，点击向上箭头展开隐藏图标。

- **弹出提醒**：有勾表示开启，点击取消勾选就暂停。
- **声音提醒**：有勾表示开启声音，取消勾选静音。暂停弹出时保留声音偏好。
- **测试弹出**：手动检查能否显示 Codex 窗口。
- **设置与状态**：也可双击托盘图标打开。
- **退出程序**：停止提醒并退出托盘。下次启动时恢复提醒。

关闭设置窗口只会收起面板。当前没有自动设置开机启动。

“设置与状态”中有 **什么时候弹出（可多选）**：可以独立勾选“回复完成时”“需要审批时”“需要回答问题时”。例如只勾“需要审批时”，就只接收审批提醒，完成和提问不会弹出或发声。全部取消则不自动提醒。总开关暂停或退出时保留这三个选项，下次启动继续沿用；默认三项都开启。手动“测试弹出”不受这些选项限制。

## 注意事项

单文件安装 EXE 可以独立发送，安装后程序在固定位置运行。请保留安装目录或 ZIP 解压后的整个文件夹，不要只移动里面 App 文件夹中的程序。如果移动或重命名安装目录，先退出旧程序，在新位置重新运行“首次安装并启动.cmd”，并审阅变更后的事件。重复安装会保留声音与三种提醒时机的选择，随后开启提醒。

浏览器或连接器的确认可能不走普通权限事件；程序还会只读检查窗口中的待审批控件。同一个待审批界面只提醒一次。未显示或未向 Windows 暴露控件的审批可能漏报。这项补充检测已通过原生测试窗口检查，其他聊天的真实待审批弹回仍需验证。

运行命令或开始申请权限不直接触发审批弹窗。审批提醒以持续存在的待审批界面为准，需要连续两次检测确认；短暂出现后自动批准的确认界面会被忽略。

完成提醒表示一个聊天回合结束。程序会显示 Codex 主窗口，不自动切到具体聊天。锁屏、安全桌面、部分全屏程序或 Windows 焦点限制可能阻止弹回；不会修改系统全局焦点设置。

## 配置与停止使用

三个提醒事件写入当前用户的 `CODEX_HOME\hooks.json`，未设置 CODEX_HOME 时使用 `%USERPROFILE%\.codex\hooks.json`；不会把发送者的配置复制到收件人电脑。原配置的备份和诊断日志在 `%LOCALAPPDATA%\CodexAttention`，日志不记录对话、审批内容或凭据。

开关保存在本文件夹的 `Config\settings.json`。程序需要此目录可写；不建议放进 Program Files。

不再使用时，先从托盘选择“退出程序”，再在 Codex 事件配置中移除带有 `CodexAttention` 的三个事件。不要移除其他程序的事件。最后可自行删除解压的文件夹。

这是自行构建的工具，未购买代码签名证书。Windows 或安全软件可能提示发布者未知；请确认文件来自可信的发送者，并检查软件来源，不需要关闭系统防护。压缩包不含聊天记录、账户配置、历史日志或开发测试目录。
