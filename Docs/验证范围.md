# 验证范围

公开版本：2026.10.13.3。主要检查在 Windows 11、.NET Framework 4.8 和 125% 显示缩放环境完成。

## 已检查

- 事件分类、不应提醒的普通工具事件、暂停及异常时返回空 JSON。
- 真实 Windows PowerShell 标准输入读取中文、表情和 UTF-8 JSON。
- 三种类型的八种组合；申请权限本身不弹窗，确认待审批后的信号遵循审批开关。
- 未选事件在窗口操作与声音前停止；总开关和托盘存活保护有效。
- 旧配置兼容，配置更新、启停与重启保留声音、类型偏好和无关字段。
- 托盘启动、暂停、恢复、单实例和退出；只控制本项目的测试实例。
- 实际设置控件和菜单同步，单项、多项、全关及外部更新同步。
- 独立进程原生无障碍夹具：中英文审批、已解决和普通控件排除、去重；首次或短暂待审批不立即提醒，同一界面连续确认后才提醒，未点击决策按钮。
- ZIP 解压到新的中文和空格路径，安装保留原事件、不重复注册。
- EXE 真实解包、15 个文件逐一校验、重复解包保留设置和其他文件、独立目录快捷方式、应用读取配置与独立事件安装。
- 实际控件离屏渲染的界面预览已检查；未接管用户窗口。

## 实际观察与尚未验证事项

开发机曾观察真实完成和权限事件成功切到前台，也有窗口已显示但 Windows 未授予键盘焦点的记录。因此不能保证所有程序、全屏、锁屏或桌面环境均可抢到前台。

实际 Codex 窗口的审批探测执行时没有待审批。夹具通过不等于所有连接器、浏览器确认和其他聊天的审批都能识别，仍依赖 Codex 暴露相关控件或状态。

另一台电脑的完整交互安装、事件信任和真实提醒，以及 Windows 10、多屏、远程/云端场景尚未完整实测。安装检查仅用独立目录和配置，不修改实际桌面或用户 Codex 配置。
